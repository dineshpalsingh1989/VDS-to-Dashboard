FROM SENSOR TO BROWSER

Explore here. Run with your own data locally.

VDS130
Measurements→MQTT broker
Your network→Condition Monitor
Python + SQLite→Dashboard
Your browser

The full application ingests MQTT messages, stores measurement history in SQLite, and exposes a browser dashboard. Optional Modbus TCP and OPC UA services share selected values and quality with other systems.

This GitHub Pages demo is a separate browser-only preview. It uses synthetic data and has no broker, database, or equipment connection.

Try these three things

  1. Choose Rising vibration and inspect the pump drive-end channel.
  2. Open Vibration diagnostics and switch between Hz and orders.
  3. Choose Missing sensor to see a stale measurement separated from reporting channels.

About the monitoring agents

The full app has six advisory checks covering connectivity, sensor freshness, data quality, storage, baseline changes, and a health summary.

This demo presents sample scenarios; it does not execute those checks or introduce changes to the agent code.
